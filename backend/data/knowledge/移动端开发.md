# 移动端开发 方向岗位知识库

> 数据来源：2026-10 Boss直聘登录态浏览×2（用户授权、人工节奏；华为座舱/中科创达 + 车载HMI公司）。画像级调研（v2.2-2 第二批）。运行期只读。

## 典型岗位职责

- Android/iOS 客户端（App）的模块设计、开发和调试，按期交付
- 性能与稳定性优化：内存占用、耗电、网络、UI 渲染的分析与优化，稳定性治理
- 参与商业级应用的完整开发周期；车载方向做智能座舱 App 定制化开发
- 与产品/后端/测试协作，输出设计文档，跟进需求落地

## 常见硬性要求

- 本科及以上，计算机相关专业（部分岗重背景经验轻学历）
- 精通 Java / Kotlin（Android）或 Swift/OC（iOS）；深入面向对象与常用设计模式
- 熟悉 Android UI 框架与系统组件、屏幕适配、多线程
- 扎实编程与算法功底，至少参与过一个完整商业级应用
- 加分：车载/系统级 App 背景、性能优化经验、aspice 流程（车载）、跨端（Flutter/RN）

## 高频技能栈

- 语言：Java、Kotlin（Android 主流）；Swift（iOS）
- 框架：Android SDK/Jetpack（Compose/ViewModel/Coroutines）、OkHttp/Retrofit/Glide
- 工具：Android Studio、ADB、Profiler（性能分析）、Git
- 车载特有：智能座舱 HMI、系统级 App、aspice 开发流程（需求/SD/DD/UT/IT 文档）

## 面试高频考察点

- 语言基础：Java 集合/并发/JVM（同后端）；Kotlin 特性（空安全/协程/扩展函数）
- Android 四大组件与生命周期；Activity 启动模式；Fragment 通信
- UI：RecyclerView 缓存机制、事件分发、绘制流程（measure/layout/draw）、屏幕适配
- 性能：内存泄漏（LeakCanary/Handler）、ANR 排查、卡顿优化、启动优化
- 并发：线程池、Handler 消息机制、协程原理
- 网络/存储：OkHttp 拦截器、SP/MMKV/SQLite/Room
- 架构：MVC/MVP/MVVM 对比、组件化/模块化、依赖注入
- 项目深挖：最难的性能/稳定性问题怎么定位解决；完整 App 上架经历
- 手撕：算法题（链表/字符串）+ 可能的手写单例/生产者消费者

## 市场趋势（2026 信号）

- **车载化明显**：座舱 App 岗位多（华为系生态链公司大量招人），要求系统级理解与流程规范
- 跨端与 Compose 声明式 UI 是加分主流；纯 iOS 岗位相对收缩
