# AI开发（大模型应用开发）方向岗位知识库

> 数据来源：2026-10 实习僧公开职位调研（5个精读JD：AI大模型开发实习/大模型应用开发×2/量化公司大模型工程化等 + 列表页采样约50岗），面试考察点结合公开面经（牛客/CSDN/字节Agent实习真题等）。运行期只读。

## 市场概况

- 实习岗位量大且增速最快（搜索"大模型开发/AIGC"全国数百岗），公司类型跨度大：大厂、模型公司、量化、SaaS、初创
- 岗位形态两类：偏工程（API/后端/部署/集成）与偏算法（微调/训练/RL）；实习以前者为主
- 部分量化/研究型岗位要求硕士及以上；多数工程型岗位本科可投
- "vibe coding深度用户"已开始出现在JD要求里（2026新现象）

## 典型岗位职责（按样本出现频次排序）

高频：
- 参与大模型应用/Agent系统的设计、开发与优化（含API接口、数据处理流程）
- 基于 LLM 构建 Agent 应用：任务规划、记忆管理、多Agent协作、工具调用、异常兜底
- 集成 MCP/Tool/知识库/企业系统，完成 Prompt 与工作流优化
- 模型部署、调试、线上问题定位，保障业务场景稳定运行

中频：
- 建立场景评测集与线上监控，优化任务成功率/准确性/时延/成本
- 与产品/算法/FDE协作完成 PoC 到生产落地，沉淀可复用方案
- 参与RAG系统建设（检索、分块、重排）

低频（偏算法岗）：
- 了解微调技术、强化学习，参与推理模型训练
- 大模型与现有数据系统/交易系统的集成（量化等）

## 常见硬性要求

- 本科及以上（工程型），计算机/AI/软件工程/数据科学相关专业优先；部分研究型要求硕士
- **熟练 Python，熟悉 FastAPI/Flask/Django 之一**——工程岗标配；Go/Java/C++在部分公司要求
- **熟悉 LLM 应用与 Agent 架构：Prompt Engineering、RAG、Tool Use、记忆机制、多Agent协作**——核心考点
- **熟悉 LangGraph / LangChain / LlamaIndex / AutoGen 至少一种框架**——高频明确要求
- 了解机器学习/深度学习基本原理
- 良好编程习惯、自驱力、问题解决能力
- 加分：真实业务场景Agent开发经验、Golang/TS、前端（Vue/React）、vibe coding经验、大模型项目落地

## 高频技能栈

- 语言：Python（事实标准）、Golang/TypeScript（部分）、C++（量化）
- 后端：FastAPI/Flask、API设计、服务化部署、Docker
- LLM栈：OpenAI兼容API、Function Calling、流式响应、LangGraph/LangChain、MCP、向量库选型（字节真题考过）、RAG全链路（分块/嵌入/检索/重排/引用）、评测（命中率/回查率/成本）
- 数据：SQL、数据处理
- 工程：Git、CI、单元测试、日志排查

## 面试高频考察点

- Agent设计：状态机vs自主Agent的取舍；多Agent怎么分工；记忆怎么设计；工具调用失败怎么兜底
- RAG深挖：分块策略、双路召回/RRF、重排、低置信补检、引用溯源、幻觉防范（字节/产品岗都爱考）
- RAG vs 微调 vs 长上下文的选型
- 工程题：LLM应用怎么做评测体系；token成本怎么优化；线上问题怎么定位（如静默丢数据类问题）
- 编程基础：Python手撕（装饰器/生成器/字符串处理）、SQL、简单算法
- 项目深挖（最重要）：简历里的AI项目——为什么自研/为什么选这个架构、量化指标怎么测的、踩过什么坑
- 对新模型/新框架的关注度与快速实验能力
- 安全意识：提示词注入防护、PII脱敏、写操作的确认机制

## 大中小厂差异

- 大厂/模型公司：框架细节+评测+工程规范考得深，可能考向量库/检索引擎选型（ES等）
- 量化/金融：加考C++、数据结构、系统一致性
- 初创：考全栈交付速度（前后端都能上）、vibe coding熟练度、一个人扛完整应用
