# AI产品 方向岗位知识库

> 数据来源：2026-10 实习僧公开职位调研（5个精读JD：百度/小米系/AI平台公司/清华系初创等 + 列表页采样约40岗），面试考察点结合公开面经。覆盖大厂/中型/初创。运行期只读。

## 市场概况

- 实习岗位量大（搜索"AI产品经理"全国约数百岗在招），是 AI 方向中偏文的入口
- 大厂（百度/字节/阿里/小米）多按细分业务线招：网盘Agent、商业产品、开发平台等；中小厂和初创多为通用AI产品岗，兼做调研/文档/测试
- 正式岗普遍要求 1-3年产品经验或AI产品实习经历；实习转正窗口常见

## 典型岗位职责（按样本出现频次排序）

高频（多数岗位都有）：
- 参与AI产品（含 Agent 功能）的需求分析、方案设计与功能迭代
- 跟进产品上线后的用户反馈与数据表现，持续优化
- 跟踪国内外大模型技术/产品进展，结合业务场景做AI产品创新
- 跨团队协作：与研发、算法、设计团队推动功能从方案到上线

中频（大厂/平台型岗位）：
- 用户需求调研、竞品分析、行业动态收集并形成报告
- PRD撰写、版本规划与项目推动
- 面向行业场景推动智能体产品/端到端解决方案落地

低频（初创）：
- 产品测试、原型（低保真）设计、文档维护、用户反馈整理

## 常见硬性要求

- 本科及以上，计算机/AI/软件工程/数学/市场营销等相关专业优先（非硬卡）
- **高频重灾区：熟悉 Prompt、RAG、Agent、工作流、Memory 等核心概念，日常重度使用主流AI产品（ChatGPT/豆包/千问/元宝等），对AI产品体验有自己的判断**——几乎所有岗位都考
- 逻辑分析、需求拆解与产品方案设计能力
- 沟通协作能力（与算法/研发/设计高效合作）
- 数据分析能力，SQL 常被明确要求（大厂）
- 加分：AI产品实习经历、AI coding 经验、智能体/MaaS平台产品经验、0-1产品规划

## 高频技能栈

- 概念层：LLM 原理认知、RAG、Agent/多智能体、Prompt Engineering、微调 vs RAG 的取舍、MaaS
- 工具层：主流AI产品使用经验、AI编程工具（加分）、Axure/Figma低保真原型（初创）
- 数据层：SQL、基础数据分析
- 文档层：PRD、竞品分析报告、方案文档

## 面试高频考察点

- AI基础概念辨析：RAG / Agent / LLM 的区别与联系；RAG与微调怎么选；幻觉怎么防
- Transformer基本原理与大模型能力边界的认知（产品视角）
- 场景题：给一个业务（如网盘/电商客服），设计一个AI功能——考察需求拆解、人机协作流程、失败兜底
- AI产品思维：模型不确定性与产品体验的取舍；什么场景该用AI什么场景不该
- 数据题：上线后如何评估AI功能效果（任务成功率/时延/成本/留存）
- 项目深挖：简历项目里AI判断的依据、量化的效果
- 反问环节质量（看对AI产品的理解深度）

## 大中小厂差异（出题参考）

- 大厂：偏专精模块（如只做网盘Agent的交互）、考SQL和数据敏感度、流程规范
- 中厂/平台型：考产品规划能力、PRD、跨团队推动
- 初创：考全流程动手（调研→原型→测试）、学习速度、对AI软硬件结合的理解
