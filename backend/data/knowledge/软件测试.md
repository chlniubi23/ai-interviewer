# 软件测试 方向岗位知识库

> 数据来源：2026-10 Boss直聘登录态浏览×2 + 实习僧公开职位精读×1（质量中台型测开实习）。画像级调研（v2.2-2 第二批）。运行期只读。

## 典型岗位职责

- 功能测试/回归测试：业务流程梳理、测试用例设计与执行、缺陷跟踪闭环
- 自动化测试：编写 UI/接口自动化脚本（Selenium/Playwright/Pytest），维护与提升稳定性
- 专项测试：使用压测平台、故障模拟平台、数据工厂等工具；性能/稳定性测试
- 质量平台开发（测开高配岗）：参与质量中台/测试工具的开发

## 常见硬性要求

- 本科及以上（实习岗计算机/软件工程优先；下沉岗位大专可、专业不限）
- 测试理论：测试流程、用例设计方法（等价类/边界值/场景法）
- Python 或 Java 代码基础（测开方向必备）、数据库基础 SQL
- 细致耐心、责任心、沟通能力
- 加分：Selenium/Playwright/Pytest 经验、Linux、接口测试（Postman/requests）、性能测试

## 高频技能栈

- 理论：测试用例设计、缺陷生命周期、质量保障体系、测试左移/右移
- 工具：Selenium/Playwright、Pytest/unittest、Postman/JMeter、Git、Linux 常用命令
- 代码：Python（主流）、Java；SQL 查询
- 平台：压测平台、故障模拟、数据工厂（大厂内部工具体系）

## 面试高频考察点

- 用例设计现场题：给一个登录页/电梯/水杯设计测试用例（考全面性：功能/边界/异常/安全/兼容/性能）
- 自动化：Selenium 定位方式、显式等待 vs 隐式等待、PO 模式；Playwright 与 Selenium 区别
- Python 基础手撕：字符串处理、列表去重、装饰器
- 接口测试：怎么做接口测试（参数/断言/依赖）；Postman 断言；抓包（Fiddler/Charles）
- 数据库：手写 SQL（join/分组聚合）
- 场景排查：线上 bug 定位思路（日志→复现→范围缩小→分流前后端）
- 质量思维：什么适合自动化、自动化收益怎么评估；缺陷怎么管理
- 项目深挖：自动化项目框架结构、覆盖率、遇到的困难
- HR 题：为什么选测试不选开发（高频，需真实逻辑）

## 市场两极信号（2026）

- 高配：测开=半个开发（写框架/平台/工具），大厂卡计算机专业+代码能力
- 下沉：大量"辅助测试/坐岗"岗（点工），门槛低但成长与薪资天花板也低——面试甄别工作内容里自动化/代码占比
