# 算法工程师 方向岗位知识库

> 数据来源：2026-10 Boss直聘登录态浏览×2（用户授权；后训练算法 + 自动驾驶）+ 领域校准。画像级调研（v2.2-2 第二批）。运行期只读。

## 典型岗位职责

- 传统线：推荐/搜索/广告/CV/NLP 算法的设计、训练、上线与迭代；特征工程与模型优化
- 大模型线（2026 增长最快）：后训练系统与数据流程搭建——SFT 微调、DPO/RLHF 偏好优化、模型对齐与能力蒸馏
- 数据体系：训练数据集构建、标注规范制定、用户反馈闭环，基于真实交互数据迭代
- 评测体系：建立可量化的模型/算法效果评估，持续迭代
- 与工程/产品协作，把算法能力工程化并稳定上线

## 常见硬性要求

- 硕士及以上为主流（顶会论文/竞赛获奖可破格），计算机/数学/自动化等相关专业
- 数学功底：线性代数、概率统计、优化
- 熟练 PyTorch；经典岗要求 TensorFlow/Hugging Face/Transformers
- 机器学习/深度学习基础扎实；能独立完成"数据清洗→训练→评测→上线"闭环
- 大模型线：精通 SFT/DPO/RLHF，熟悉 TRL/DeepSpeed/PEFT 等框架，有开源底座（Qwen/LLaMA）实操
- 加分：Kaggle/顶会、大模型场景落地（对话/陪伴/Agent）、推理优化

## 高频技能栈

- 基础：机器学习（树模型/集成）、深度学习（CNN/Transformer/注意力机制）
- 大模型：Transformer 原理、预训练与后训练（SFT/DPO/RLHF/蒸馏）、LoRA/QLoRA、推理部署（vLLM）
- 工程：PyTorch、Hugging Face 全家桶、DeepSpeed/Megatron（分布式）、Python 工程
- 评测：benchmark 构建、人工评估规范、A/B

## 面试高频考察点

- 数学基础：贝叶斯/极大似然、梯度下降家族、过拟合应对、偏差方差
- 机器学习八股：LR/SVM/树模型/XGBoost 原理与对比、正则化、特征选择
- 深度学习：反向传播推导、BN/LN、注意力机制计算细节、位置编码
- 大模型（高频新贵）：预训练 vs 微调 vs RAG 怎么选；SFT 数据怎么构造；RLHF/DPO 流程与区别；幻觉缓解；LoRA 原理；推理加速（量化/KV cache）
- 推荐系统线：召回-粗排-精排架构、协同过滤、双塔模型、特征交叉
- 手撕代码：LeetCode 中等 + 机器概率题（如采样/贝叶斯）+ 可能的手写 attention
- 论文/项目深挖：动机、方法、与你相关的增量、复现细节、量化效果
- 业务结合：怎么定义离线指标与在线指标的一致性

## 市场信号（2026）

- 大模型后训练/AIGC 岗位爆发（To C 出海公司大量招），传统 CV 算法收缩
- 自动驾驶方向稳定但卡背景；"算法+工程双能力"（能部署能优化）最稀缺
