# 前端开发 方向岗位知识库

> 数据来源：2026-10 实习僧公开职位精读×2（小程序/工业软件方向）。画像级调研（v2.2-2 第一批）。运行期只读。

## 典型岗位职责

- Web/小程序前端页面开发、组件封装与交互实现
- 对接后端接口，完成数据渲染、状态管理与联调排障
- 性能与体验优化：加载速度、渲染性能、多端兼容（响应式/真机调试）
- 数据可视化大屏、图表、时间线等业务模块开发
- 参与代码评审、技术文档维护与版本发布

## 常见硬性要求

- 本科或硕士在读，计算机/软件工程/数字媒体相关专业
- 扎实 JavaScript（ES6+）/HTML5/CSS3 基础，理解组件化开发与常见布局
- 熟悉 Vue 或 React 至少一种主流框架，有项目实践
- 理解 HTTP 接口调用、异步编程、前端状态管理
- 熟悉 Git 协作流程
- 加分：微信小程序（原生/Taro）、TypeScript、ECharts/D3/Three.js 可视化、有可展示的个人项目/开源贡献

## 高频技能栈

- 三件套：HTML5/CSS3/JavaScript(ES6+)、TypeScript（越来越默认）
- 框架：Vue3/React（含生态：Vuex/Pinia、Redux/Zustand）、组件库（Element/Antd）
- 小程序：微信原生、Taro/uni-app 跨端
- 可视化：ECharts、D3.js、Three.js/WebGL（工业/大屏场景）
- 工程：Vite/Webpack、Git、真机调试与兼容性测试

## 面试高频考察点

- JS 核心：闭包、原型链、事件循环（宏/微任务）、Promise/async、手写（防抖节流/深拷贝/继承）
- CSS：盒模型、Flex/Grid、BFC、居中方案、移动端适配（rem/vw）
- 框架原理：Vue 响应式/双向绑定/diff/组件通信；React Hooks 原理/Fiber 概念
- 网络：HTTP 方法/状态码、缓存（强缓存/协商缓存）、跨域方案、HTTPS 握手
- 性能优化：首屏加载、懒加载、长列表渲染、打包优化（结合项目问）
- 工程化：模块化演进、Vite/Webpack 区别、组件设计
- 项目深挖：技术选型理由、遇到的兼容性/性能问题怎么解决
- 手撕：DOM 操作题、简单算法（数组去重/扁平化）、CSS 布局实现

## 场景差异

- 小程序/C 端：重交互体验、真机兼容、视频/直播能力
- B 端/工业软件：重数据可视化（大屏/三维）、复杂表格表单、多端适配
