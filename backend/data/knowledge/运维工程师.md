# 运维工程师 方向岗位知识库

> 数据来源：2026-10 Boss直聘登录态浏览×2（用户授权；云原生 SRE 校招型 + 实施交付型）。画像级调研（v2.2-2 第二批）。运行期只读。

## 典型岗位职责

- 系统与基础设施日常维护监控：服务器、网络设备、云资源
- 故障响应与排查：性能瓶颈（CPU/内存/IO/网络）、连接耗尽、时延飙升等定位修复
- 中间件高可用运维：Nginx/MySQL/Redis/Kafka 的备份、主从、故障切换、容量治理
- CI/CD 与发布：镜像构建、制品管理、版本回滚与发布规范
- 自动化与平台化：用 Shell/Python/Go 写运维工具，推动 IaC（Terraform/Ansible/Helm）
- 实施交付型：IDC 机房、门禁/监控等弱电设备维护、现场部署

## 常见硬性要求

- 本科及以上（校招型）或大专（实施型），计算机相关专业
- 熟悉 Linux 系统与网络排障（必备）
- 至少一种自动化语言：Shell/Python/Go
- 云原生岗：Kubernetes 深入理解（Pod/Deployment/Service/Ingress/RBAC/CNI/CSI），云产品实践（阿里云 ECS/VPC/OSS/RDS/SLS 等）
- CI/CD 工具链：Jenkins/GitLab CI；加分解题：ACK 深度经验、Istio/灰度发布、可观测体系（Prometheus/Grafana/Loki/Tracing）、IaC、SLO/错误预算

## 高频技能栈

- 系统：Linux（进程/内存/IO/网络）、TCP/IP、DNS、负载均衡
- 云原生：Kubernetes/Docker/Helm、阿里云/腾讯云全家桶
- 可观测：Prometheus/Grafana、ELK/Loki、Jaeger/SkyWalking
- 自动化：Shell、Python、Ansible/Terraform
- 中间件：Nginx/MySQL/Redis/Kafka 运维

## 面试高频考察点

- Linux 排障现场题：CPU 100% 怎么查（top/pidstat/perf）；磁盘 IO 高怎么定位；内存泄漏分析
- 网络：TCP 三次握手/四次挥手、TIME_WAIT 过多怎么办、连接耗尽排查；DNS 解析过程
- Kubernetes：Pod 生命周期、Service 类型与 kube-proxy、Pod 起不来怎么排查（kubectl describe/logs）、HPA 弹性伸缩
- 场景题：网站突然变慢怎么排查（链路：DNS→LB→服务→DB）；怎么做一次不停机发布
- MySQL/Redis：主从复制原理、哨兵/集群、备份恢复策略、慢查询配合 DBA 处理
- Shell/Python 手撕：日志分析脚本（awk/sed/管道）、统计 topN IP
- 监控：PromQL 基础、怎么做告警策略（阈值/告警风暴治理）
- 项目深挖：亲手处理过的故障（STAR 讲清楚定位链路）

## 市场两极信号（2026）

- 云原生 SRE 方向要求大幅提高（K8s 是硬门槛，IaC/可观测是强加分），校招偏爱体系化能力
- 实施交付型（IDC/弱电/驻场）门槛低但成长有限——面试问清是否含云平台/K8s 工作
