# FDE（前瞻部署工程师/解决方案工程师）方向岗位知识库

> 数据来源：2026-10 实习僧公开职位调研（4个精读JD：能源AI战略解决方案/AI应用解决方案/传统售前解决方案等 + 列表页采样）。FDE在国内招聘中常以「AI解决方案工程师」「技术解决方案」「售前+交付混合」形态出现。运行期只读。

## 市场概况

- 实习岗位数量少于AI产品/AI开发，但2026年增长快（企业AI落地需求爆发）
- 名称杂：Forward Deployed Engineer / AI解决方案工程师 / 技术顾问 / 售前+PoC；判断标志是「客户场景 + AI方案验证 + Demo交付」三件套
- 行业分布：能源、制造、金融、政务、审计等垂直行业数字化团队；大模型公司（智谱/字节等）的FDE团队直接对接客户落地
- 正式岗普遍要求能独立带PoC到生产落地；实习岗以协助为主

## 典型岗位职责（按样本出现频次排序）

高频：
- 深入理解客户业务流程，与客户及内部团队梳理需求，识别痛点与价值机会
- 基于业务需求做 Prompt 设计、知识库构建、工作流编排及效果测试
- 协助完成 PoC（概念验证）和 Demo 开发，验证AI方案可行性和业务价值
- 输出方案文档、演示材料、用户故事及技术调研报告

中频：
- 参与AI Agent、大模型、多智能体技术在行业场景的应用研究
- 协助客户交流、需求访谈、方案宣讲及项目汇报
- 配合产品/算法/研发推动解决方案落地
- 设计可运行 Agent 原型：提示词与上下文设计、工具调用、知识检索、任务编排、对接业务API

低频（传统售前型）：
- 投标方案文件与标书制作、售前PPT

## 常见硬性要求

- 本科及以上，计算机/AI/软件工程/数据科学/自动化/电子信息相关专业（部分传统能源行业放宽到理工/规划类）
- **熟悉大模型（LLM）、Agent、RAG、知识图谱等AI技术体系**——高频
- **Python开发能力**（独立完成数据分析、模型调用、基础应用开发）——高频；部分岗位要求 JS/TS
- 有 Prompt Engineering、AI Agent 开发、AI应用落地经验者优先
- 表达与文档能力：方案书写作、客户宣讲
- 技术与业务融合思维：从实际问题出发探索AI落地
- 加分：AI项目/科研/开源/竞赛经历、行业知识（能源/金融等）

## 高频技能栈

- AI层：LLM API、Prompt设计、RAG/知识库构建、Agent/工作流编排（LangGraph/Dify类）、多智能体协作
- 工程层：Python（必备）、API集成、简单前后端原型、部署调试
- 业务层：需求分析方法、业务流程建模、PoC设计、ROI论证
- 软技能：客户沟通、方案表达、跨团队协调

## 面试高频考察点

- 场景设计题（核心）：给一个传统行业场景（如风电运维/审计/客服），如何引入AI——考察需求拆解→技术选型（RAG还是Agent还是工作流）→PoC设计→效果评估的完整链路
- 技术辨析：什么问题用RAG解决、什么用Agent、什么用确定性工作流；如何权衡幻觉风险与业务容错
- Prompt与知识库实操：给个任务现场设计Prompt/知识库结构
- 客户视角：如何向非技术客户讲清AI方案的价值与边界；遇到客户不合理预期怎么管理
- 评估意识：任务成功率/准确性/时延/成本怎么量化验证
- 项目深挖：简历项目中的取舍、踩坑、量化成果
- 沟通表达本身的考察（FDE面试即工作预演——讲清楚比答对更重要）

## 大中小厂/行业差异

- 大模型公司FDE：偏技术，Agent编排/评测能力要求高，像"会写代码的顾问"
- 行业数字化团队：偏业务，行业理解+方案文档+客户交流权重高，AI技术够用即可
- 传统售前型：文档/PPT/投标为主，AI是加分项——面试前要看清岗位成色
