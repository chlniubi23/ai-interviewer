# Java 后端 方向岗位知识库

> 数据来源：2026-10 实习僧公开职位精读×2 + Boss直聘登录态浏览×1（用户授权、人工节奏逐页阅读）+ 早期 LLM 生成画像校准。画像级调研（v2.2-2 第一批）。运行期只读。

## 典型岗位职责

- 参与后端业务系统的需求分析、方案设计与核心模块编码开发、单元测试
- 接口开发与数据库设计/优化，保障系统稳定、高效、可扩展
- 参与项目从 0 到 1 搭建、开发、上线部署全流程（中小厂高频）
- 系统日常维护、Bug 修复、性能调优；配合前端/产品联调，输出开发文档
- 中间件与缓存/消息队列的使用（Redis、RabbitMQ/Kafka）

## 常见硬性要求

- 本科及以上（部分中小厂大专可），计算机相关专业
- 扎实 Java 基础与面向对象设计；熟练 Spring Boot / Spring Cloud / SSM（高频）
- 熟练 MySQL（InnoDB 原理、SQL 调优），会用 Redis；MQ（RabbitMQ/Kafka）常见
- 熟悉 Linux 常用命令、Git/Maven；了解 Nginx/Tomcat、Docker 部署加分
- 加分：微服务/分布式/高并发项目经验、ERP/电商/供应链业务经验、若依框架、前端了解

## 高频技能栈

- 语言与框架：Java、Spring Boot、Spring Cloud、MyBatis/MyBatis-Plus
- 数据与中间件：MySQL/PostgreSQL、Redis、RabbitMQ/Kafka、ElasticSearch（部分）
- 工程与部署：Git/SVN、Maven、Linux、Nginx、Docker/K8s（了解级）
- 场景：电商中台、ERP、SaaS 业务系统

## 面试高频考察点

- Java 基础八股：集合（HashMap/ConcurrentHashMap）、并发（线程池/JUC/volatile/CAS）、JVM（内存区域/GC/类加载）
- Spring 原理：IOC/AOP、Bean 生命周期、事务传播、Spring Boot 自动装配
- 数据库：索引原理与慢查询优化、事务与隔离级别、SQL 手写（join/聚合）
- Redis：缓存穿透/击穿/雪崩、持久化、分布式锁
- 场景设计：短链/秒杀/库存扣减；接口幂等；分库分表思路
- 项目深挖：架构选型理由、最难 bug、0-1 上线经历（中小厂特别爱问部署）
- 手撕：中等算法题（字符串/链表/二叉树）

## 大中小厂差异

- 大厂：八股深、系统设计题多、要求分布式经验
- 中小厂：重"能独立扛模块+能部署上线"，业务系统（ERP/电商）经验吃香，八股适中
