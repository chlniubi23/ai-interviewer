# UI设计 方向岗位知识库

> 数据来源：2026-10 实习僧公开职位精读×1（完整型 UI 岗）+ 领域校准。画像级调研（v2.2-2 第二批）。运行期只读。

## 典型岗位职责

- Web/移动端界面视觉设计：独立完成页面、图标、组件设计，输出设计稿/切图/标注
- 跟进前端还原，把控视觉落地质量
- 基础交互设计：梳理用户任务流程，输出线框图/原型，设计页面跳转与操作反馈，撰写交互说明
- 参与需求评审，从视觉与体验角度提优化建议
- 搭建维护组件库与视觉规范，保障视觉体系统一

## 常见硬性要求

- 本科及以上应届，视觉传达/数字媒体/交互设计/工业设计等相关专业优先
- **必须提供作品集**（含 UI 视觉 + 交互原型案例）——硬门槛
- 扎实视觉功底：色彩、排版、图形；熟练 Figma，掌握 PS/AI
- 基础交互能力：Axure/墨刀原型，理解信息架构与用户流程
- 沟通协作好、能接收反馈迭代
- 加分：真实项目上线经验、竞赛/商业项目、动效（AE/Principle）、3D（Blender/C4D）

## 高频技能栈

- 设计工具：Figma（主流）、PS/AI、Sketch（存量）、即时设计（国产）
- 原型：Axure/墨刀/Figma 原型
- 规范：设计系统（组件库/Design Token）、iOS/Material 规范、B 端设计规范（Ant Design）
- 动效与加分：AE/Lottie、C4D/Blender、AIGC 工具（Midjourney/即梦 辅助）

## 面试高频考察点

- 作品集深挖（核心，占面试 60%+）：为什么这样设计、设计过程（调研-草图-迭代）、面对反馈怎么改、如何平衡美观与可用
- 视觉基础：色彩搭配原理（对比/邻近色）、字体与排版层级、留白；给页面找问题并优化（现场改稿）
- 组件与规范：怎么做组件库；什么情况用现有组件 vs 定制
- 交互：拿到一个需求怎么拆解成页面流程；B 端表格/表单的体验细节
- 协作：怎么和产品意见冲突时沟通；怎么保证前端还原度（标注/走查）
- 趋势题：对 AI 生成设计怎么看、怎么用 AI 提效（2026 高频）
- 现场小测：可能给 30-60 分钟出一版视觉稿或找 10 个体验问题

## 作品集提醒（求职核心资产）

- 3-5 个完整项目 > 10 个练习稿；每个项目讲清背景/目标/过程/结果
- 展示"过程与思考"比纯效果图更能打动面试官；附一个 B 端 + 一个 C 端覆盖面最佳
